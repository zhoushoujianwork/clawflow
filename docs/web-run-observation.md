# 局域网只读观察运行

团队成员可以在自己电脑的浏览器里看任务的运行状态、实时日志和 worker，不需要装 App，也不能改任何东西。

## 开启

在运行 controller 的机器上：

```bash
clawflow web --host 0.0.0.0 --remote readonly --allow-cidr 192.168.0.0/16
```

`--allow-cidr` 可以重复，限定哪些网段可访问；不写则不限网段。其他电脑打开 `http://<这台机器的局域网地址>:8090/jobs`。

本机（回环地址）打开同一个地址仍是完整权限，其余机器一律只读。

## 页面

| 页面 | 内容 |
| --- | --- |
| `/jobs` | 运行列表，按仓库和 issue/PR 分组。每行：状态（排队、运行、成功、失败、取消）、阶段（实现、修复 CI、修复（验收）、验收、回复）、所在 worker、耗时、触发原因。可按状态和仓库筛选。 |
| `/jobs/<id>` | 单次运行：阶段时间线、实时日志、结束后的结果和链接（PR、分支、提交、验收结论）、同一 issue/PR 的其他运行。 |
| `/runners` | 每个 worker：在线状态、标签、角色、正在跑的任务、最近连接和最近心跳。 |

状态只表示这个任务本身。“成功”不代表 CI、验收或合并已经完成。

### 实时日志

- 来自该次执行已存储的 Offload 输出，由 controller 提供；不会启动执行，也不会连接 worker。
- 复用运行详情的 trace 组件显示工具调用与结果。视图在底部时自动跟随，向上滚动后停止跟随。
- 连接断开后自动重连（1 秒起，最长 15 秒），并从已收到的最后一条继续，不重复、不漏行。执行结束后连接关闭。
- 日志缺失时会说明原因：尚未采集、已过期、未启用采集、后端不支持等。
- 同时在线的实时日志连接上限 32 个，超出返回 503，页面会稍后重试。

### 新鲜度

页面每 3 秒刷新。请求失败或数据过旧时，顶部提示“连接中断”，转圈停止，耗时不再增长，并保留最后一次收到的数据。耗时从 controller 记录的该次执行开始时间算起；没有记录则显示“—”。

## 只读与脱敏

**写操作被拒绝。** 非本机来源只能对白名单内的路径发 `GET`/`HEAD`；其余方法和路径返回 403，请求不会到达处理函数。白名单新增：`/api/jobs`、`/api/jobs/<id>`、`/api/jobs/<id>/logs`、`/api/runners` 及对应页面。设置、令牌、聊天、终端、取消/暂停等接口仍是本机专用。来源只看 TCP 对端地址，不信任 `X-Forwarded-For` 等头。

**响应脱敏。** 非本机来源的每个响应在发出前都会处理（本机不处理）：

- 已配置的凭据原文（GitHub/GitLab token、各 provider 的 API key、名称以 `_TOKEN`、`_KEY`、`_SECRET`、`_PASSWORD`、`_DSN` 结尾的环境变量值）→ `[redacted]`
- 常见凭据形态（`ghp_…`、`github_pat_…`、`glpat-…`、`sk-…`、AWS 密钥、JWT、PEM 私钥、`Authorization`/`Bearer` 头、URL 里的用户名密码、`password=`/`token:` 等键值）→ `****` 或 `[redacted]`
- 本机路径（状态目录、数据目录、主目录、临时目录、各仓库的本地检出路径，以及 `/Users`、`/home`、`/var`、`/tmp`、`~/` 等开头的路径、Windows 用户目录、`file://`）→ `[path]`
- JSON 里名为 `local_path`、`workdir`、`token_file` 等的字段，以及名称含 token/secret/password/api_key 的字符串字段，整体替换；`input_tokens` 这类计数保持不变。
- 实时日志按行脱敏，不会因此延迟推送。静态页面资源不处理。

**限制。** 脱敏是模式匹配：凭据如果既没有配置过、也不符合上述形态，就无法识别。日志里的任意文本都可能出现这种情况，所以只在可信的局域网内开放，并用 `--allow-cidr` 收窄范围。

## 依赖

需要 controller 在本机运行（`settings.coordinator.enabled`）。未运行时三个接口返回 503，页面提示“Coordinator is not running on this host”。

## 默认构建

默认构建内嵌的是迁移提示页（`web-retired/`），不含这些页面。需要这些页面时用 `make legacy-web` 构建（`-tags legacyweb`）。
